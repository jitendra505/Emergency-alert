🛡️ System Features

Built for speed, reliability, and real-time communication

⚡

Real-Time Alerts

Admins receive instant push notifications the moment a new emergency is reported. Zero delay via WebSocket.

📍

Map-Based Location

Pinpoint exact incident location with interactive maps, GPS geolocation, and reverse geocoding.

📷

Image Evidence

Upload up to 4 photos per report. Images are auto-compressed for fast loading without quality loss.

🔔

Email Notifications

Automated email alerts to admins for new reports and to users when their report status changes.

📊

Live Status Tracking

Track your report from Pending → In Progress → Resolved with real-time status updates.

🔒

Secure & Reliable

JWT authentication, bcrypt password hashing, rate limiting, and input validation for enterprise-grade security.
